# 评审与交付契约（validation-checklist）

## 生成前

- [ ] `processon-setup` 状态 = configured；全程零凭据回显。
- [ ] 图形类型已写进需求（架构图含“块图、禁 UML 类表”）。
- [ ] 结构稿经 `processon-prompt` 打磨过一轮，节点/关系已定。

## 评审（processon-review）三维度

1. 结构：层级、关系、方向是否忠实表达输入语义。
2. 可读性：节点文案长度、布局密度、配色一致性。
3. 类型正确性：泳道归属、时序箭头方向、块图 vs 类表。

修订纪律：`REVISE_ONCE`——至多一轮修订；一轮修不掉的问题如实说明并交付现状。

## 交付物

- [ ] ProcessOn 可编辑源文件（必需，不接受仅图片）。
- [ ] 预览图或 DSL 文本。
- [ ] 一句话使用说明（图形类型 + 结构要点）。

## 异常路径

- [ ] 生成类错误后已对账（无重复生成）才重试。
- [ ] 图片 URL 不可访问时改用 `generate_chart` 重出预览。
- [ ] 限流时串行退避，未并行重绘。
