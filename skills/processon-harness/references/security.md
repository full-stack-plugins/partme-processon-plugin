# 安全边界（security）

## 凭据存放

- 位置：当前用户配置目录下 `processon/credentials.json`（遵循 `XDG_CONFIG_HOME`，
  Windows 使用当前用户配置目录），不在仓库、插件缓存或宿主配置内。
- 权限：文件 0600、目录 0700；原子写（临时文件 + `os.replace`）+ fsync，
  写失败保留旧凭据。
- 读取前校验目录属主与符号链接；不可信目录直接拒绝。

## 不泄漏纪律

- Token 永不出现在聊天、命令参数、日志、截图、报错信息里；`__repr__` 只报路径。
- 不要让用户把 Token 粘贴进聊天；粘贴只发生在本地配置页的密码框（页面不回显）。
- 不写入 `.mcp.json`、`.zshrc`、任何仓库文件或宿主应用配置。
- 不代查、代填、代存他人凭据；删除用户凭据必须由用户显式发起。

## 本地配置页

- 仅绑定 `127.0.0.1` 临时端口，带一次性 CSRF token 与严格 Origin 校验。
- 响应带全套安全头（CSP：`default-src 'self'`、`frame-ancestors 'none'` 等）。
- 服务有时限自动关闭；请求体限长、强制 JSON。

## 高级覆盖（开发者 / CI）

在受控子进程环境中提供原始 `PROCESSON_MCP_TOKEN` 即可跳过文件凭据；这是唯一被
支持的环境变量注入方式，凭据值同样不得出现在命令行参数里。

## 边界外

- 账号密码、套餐、云文件权限：走 ProcessOn 官方渠道。
- 创建 Token：只能由用户在 ProcessOn 用户中心完成。
